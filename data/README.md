# Source Data

This folder contains the three Excel inputs used by the Power BI forecasting prototype.

| File | Role in the model |
|---|---|
| `Net Sales actuals DATA.xlsx` | Recognized Actual Net Sales, January–August 2026 |
| `Accruals DATA.xlsx` | Remaining Project Accrual Forecast, September–December 2026 |
| `Open custom opportunities DATA.xlsx` | CRM opportunity pipeline, probability, value and allocation inputs |

The sources are deliberately kept separate because they represent different business processes and grains.

## Publication warning

These files are included because they are part of the supplied case package. Before publishing the repository publicly, confirm that redistribution of the original source data is permitted. If not, replace these files with anonymized or synthetic equivalents and update Power BI source paths accordingly.
