# Public Release Checklist

Before switching the GitHub repository to **Public**, review the following items.

- [ ] Confirm permission to redistribute the three original Excel source files.
- [ ] Confirm permission to redistribute the original case assignment document.
- [ ] Confirm the PBIX does not contain credentials, tokens, private URLs or connection secrets.
- [ ] Review Power Query data-source settings for local usernames, machine paths or internal network locations.
- [ ] Check CRM opportunity names and project identifiers for confidential or identifiable business information.
- [ ] Confirm permission to use Aalto / Aalto EE names, logos and visual branding in a public portfolio.
- [ ] If permission is uncertain, replace source data with synthetic or anonymized data.
- [ ] Clearly label generated presentation mock-ups as conceptual rather than production screenshots.
- [ ] Open the repository in a logged-out browser after publishing and verify every file that is publicly visible.

## Safer alternative

Keep the repository **Private** for interview sharing, or publish only the README, architecture images and anonymized screenshots while excluding raw source files and the PBIX.
